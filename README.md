## 💻 Sample HTML5 Code

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My HTML5 Page</title>
</head>

<body>

    <header>
        <h1>Welcome to My Website</h1>
    </header>

    <main>
        <section>
            <h2>About HTML5</h2>
            <p>I have learned HTML5 from basic to advanced level.</p>
        </section>
    </main>

    <footer>
        <p>© 2026 My Website</p>
    </footer>

</body>
</html>
```
